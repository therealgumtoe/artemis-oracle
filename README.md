# House of Artemis · Oracle

Ein digitales Orakeldeck mit 53 Karten – Göttinnen, Symbole, Wesen, Monde und Mysterien – als React-App.

## Lokal starten

```bash
npm install
npm run dev
```

Die App läuft dann auf `http://localhost:5173`.

## Deployment auf Vercel

1. Dieses Repository auf [vercel.com](https://vercel.com) importieren
2. Vercel erkennt Vite automatisch – keine weiteren Einstellungen nötig
3. Nach dem ersten Deploy bekommt man eine `*.vercel.app`-URL

## Tech

- React 18
- Vite
- lucide-react für Icons
- Reine Inline-Styles, keine externe CSS-Bibliothek
